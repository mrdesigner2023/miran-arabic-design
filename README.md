# من الأداة إلى الفكرة

موقع عربي ثابت ومجاني يجمع أداتين عمليتين للمبتدئين: **خيط تعلّم**، رفيق ممارسة Illustrator بثلاث محطات، و**مِران**، صالة أفكار فيها 48 تحدياً تصميمياً.

## التشغيل محلياً

افتح `index.html` في المتصفح مباشرةً. لا توجد حزم أو خطوة بناء أو خادم تطبيق. لاختبار الموقع عبر عنوان محلي من مجلد `site/`:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. ملفات HTML وCSS وJavaScript محلية؛ لا توجد خطوط أو صور أو مكتبات يجري جلبها من خدمات خارجية. الروابط الخارجية الوحيدة تفتح عند اختيار المستخدم فيديوهات وقوائم YouTube أو مواقع المراجع الموجودة داخل التمرين.

## المسار المقترح

1. [ابدأ من هنا: أساسيات Illustrator](https://www.youtube.com/playlist?list=PLY7HuGNwj9r0) — 5 دروس، ويبدأ رفيق الممارسة بفيديو المقدمة.
2. [أدوات Illustrator: الأشكال والرسم](https://www.youtube.com/playlist?list=PLWjYwsbOxJXk) — 7 دروس.
3. [التفكير التصميمي: من النصيحة إلى المثال](https://www.youtube.com/playlist?list=PLMuNZPv1BIi0) — درسان.

## بنية الموقع

- `index.html` و`styles.css` — صفحة البداية العربية RTL، وروابط الأدوات والقناة والقوائم.
- `practice/index.html` — نسخة من رفيق Practice Loom، محفوظة كصفحة واحدة مستقلة.
- `miran/index.html` و`miran/styles.css` و`miran/app.js` و`miran/challenges.js` — نسخة مِران وبيانات تحدياتها.

الصفحتان الفرعيتان ومحتواهما محفوظان كما بُنيا؛ التغيير الوحيد هو وضعهما داخل مسارات الموقع المناسبة كي تعمل روابط الملفات على الاستضافة الثابتة. لا تحليلات ولا إعلانات ولا تتبع. تقدم رفيق الممارسة وتحديات مِران المحفوظة يبقيان في تخزين المتصفح على جهاز المستخدم.
